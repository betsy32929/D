D夾｜本機資料救援包

用途：從同一台電腦、同一個瀏覽器、同一個網址來源，找回 D夾 localStorage 資料。
先看這裡
1
資料在那台電腦內：請一定要用原本有資料的那台電腦、原本那個瀏覽器開啟。
2
如果你平常用 GitHub Pages 網址：這個救援包要放到同一個 GitHub Pages 網站打開，才能讀到同一份 localStorage。
3
如果你平常是下載 HTML 後直接打開：請先打開你原本那份 D夾 HTML，再用下方「Console 救援碼」救資料。
一鍵掃描本機資料尚未掃描
請先按「掃描本機 localStorage」。
選localStorage 鍵名案件數規則數最後更新大小判斷
尚未掃描
「套回」會先備份目前主資料到 DCLIP_RESCUE_BACKUP_BEFORE_APPLY_時間，再把選取資料寫入 DCLIP_APP_STATE_V1。
選取資料預覽
Console 救援碼
當這個救援包讀不到資料時：打開原本有資料的 D夾頁面 → 按 F12 → Console → 貼上這段 → Enter，會下載完整救援包。
匯入救援包檢查
可用來檢查你剛下載的救援包裡有沒有案件資料。
